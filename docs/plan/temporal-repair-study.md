## Rulers before experiment

Compare an invalid draft's explicit timezone-aware range endpoints with the
validated repair, without reading the question. Protect column, base identity,
plan versus without scope, child identity, comparison direction and exact instant.
Accept the same endpoint in existing typed timestamp filters at the same scope,
or an equivalent business-zone midnight date range. No SQL generation or guessing
of a missing column. A recognized timestamp with unresolved identity/zone is
unverifiable, not evidence of preservation. A refusal can safely stop the repair.

This narrow guard does not certify the first draft, other plan changes, first-
generation mistakes, timestamp literals outside range scopes or unreadable JSON.
It is deliberately not a general plan-equivalence checker. It never repairs or
moves values itself. Rejection is a failed repair, not a necessary semantic refusal.
