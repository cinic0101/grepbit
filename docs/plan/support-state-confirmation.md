## Research ruler and controls

Freeze 18 authored cases: lease, warranty repairs and insured shipments, each
with defined / confirmed absent / undocumented configuration contexts and a
scoped question plus an unrestricted-total neighbor. Lease adapts the observed
failure family; the other contexts are new authored diagnostics, not unseen
real-user holdouts. English only, to isolate the information intervention.

Defined contexts give the approved code mapping in **every** arm. Absent contexts
have only the amount column, with no identifying field or derivation. Unknown
contexts have an opaque status code but no approved mapping: no subset answer
is justified. Unknown is not a claim that the underlying business concept does
not exist. Unrestricted sums remain answerable in all three states.

Three arms change only table comments: A existing amount/flag descriptions;
B neutral prose; C reviewed support-state facts and the limitation of using
amounts as membership evidence. No examples, SQL, gold plan or data rows in any
model message; no changed identifiers, schemas, values, gate, planner wire or
runtime defaults. No absent-concept keyword gate or retrieval implementation.

Root approves this narrow research ruler under delegated checkpoint authority.
Freeze hand arithmetic and independent SQL on four fictional instances (unequal
amounts, different code composition, NULLs, empty rows), correct plan variants
and wrong-population foils before model calls. Full values and one fixed approved
recipe must hold across instances; unlisted recipes stay unassessed, not wrong
by fiat. Raw SUM and equivalent plan/operand filter placement are included.

Report correct answers, necessary refusals, wrong answers, false refusals,
unassessed and operational failures separately. Also report typed-state matching:

should produce clarify. A different safe-refusal status is not a wrong number,
but does not pass this secondary state distinction. Do not silently tighten old
disclosed-answer scores or certify free-text refusal rationale from status alone.
