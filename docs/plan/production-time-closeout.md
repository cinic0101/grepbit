## Acceptance and limits

Freeze existing temporal cases and SQL witnesses before model calls; retain
correct answers, wrong answers, necessary refusals, false refusals, unassessed
and operational failures separately. Assert MCP-to-HTTP payload identity,
request identity, public/debug boundary, typed execution values and assumptions.
Natural tests do not claim complete DST/storage coverage; prior explicit
PostgreSQL rulers retain that separate role. Fixed known cases are regressions,
not an unseen-user generalization set.

Repair adoption requires the approved naive instant and clock controls to be
retained, known changed scope/column/operator/precision cases to be blocked,
safe declines and unrelated repairs unchanged, and bounded actual-output replay
plus service integration evidence. Unknown cases stay separately counted and
are not certified. If this evidence is insufficient, keep the candidate out of
runtime with a named blocker and a finite next decision; time delivery still
closes. No full intent-preservation claim or general repair framework.
